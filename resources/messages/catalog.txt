# Adash message catalog.
#
# Format: locale.key = ICU message string. One message per line. Blank lines
# and lines beginning with '#' are ignored.
#
# This file is the only place a user-visible Adash string exists. No Ada
# source may contain one. Keys are stable across releases -- they are part of
# the contract with translators and with conformance cases -- so renaming a
# key is a breaking change even when the English text is untouched.
#
# Adding a message: add the literal to Adash.Messages.Message_Id, give it a
# key in Adash.Messages.Key, then add the key here. The Key case statement has
# no `others`, so the Ada side cannot be forgotten; adash_check verifies this
# side, that every key Message_Id names exists here.
#
# ICU treats the apostrophe as an escape character. Messages here avoid it
# rather than doubling it, because a doubled apostrophe is invisible to
# review and renders wrongly exactly once, in the released build.
